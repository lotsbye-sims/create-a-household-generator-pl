# create-a-household-generator-pl
Nieoficjalny, fanowski generator rodzin do The Sims 4, niezwiązany z EA. Losuje gospodarstwo z historią przeprowadzki, cechy każdego domownika i działkę: świat, wielkość, budżet i budynek. Każdą część losujesz osobno, a dodatki, których nie masz, odznaczasz. Działa bez instalacji.
